# Aedox Gold Analysis Agent

A local, MT5-connected **XAU/USD market analysis and reporting dashboard**.

> **Safety policy: ANALYSIS ONLY.** This application reads market prices and historical candles. It does not place, modify, or close trades. It does not call MT5 order execution APIs. All BUY/SELL labels are analysis signals for the user to review manually.

## Features

- Live bid/ask and spread from MetaTrader 5.
- Closed-candle analysis on W1, D1, H4 and M15.
- Weekly directional bias and D1/H4 supply-demand context.
- Existing order-block (OB) and fair-value-gap (FVG) strategy.
- M15 setup confirmation with suggested entry, stop loss and target.
- Rule-based swing structure, BOS/CHoCH and liquidity sweep context.
- OHLC data-quality checks.
- Existing Random Forest setup score (not a guaranteed win probability).
- Historical strategy statistics and model metrics.
- Downloadable JSON market report and CSV signal list.
- Optional historical CSV fallback, visibly labelled as historical rather than live.

## Requirements

- Windows 10/11, 64-bit.
- Python **3.11 64-bit** recommended. MetaTrader5's Python package may not support every newest Python release immediately.
- MetaTrader 5 desktop terminal installed, open and logged in.
- The exact broker gold symbol. Set `MT5_SYMBOL` in `config.py` (examples: `XAUUSD`, `XAUUSDm`, `GOLD`).

## First-time setup

1. Extract the ZIP to a normal folder, for example `C:\\Aedox\\gold_agent`.
2. Open MetaTrader 5 and log in. No trade permission is required by this application.
3. Double-click `setup_windows.bat`. It creates `.venv` and installs Python dependencies.
4. Open `config.py` and set `MT5_SYMBOL` to the exact symbol shown in MT5 Market Watch.
5. Double-click `start_agent.bat`.
6. Open http://127.0.0.1:5000 in your browser.

Keep MT5 running while you want live market updates. The dashboard refreshes data on page visits at the configured interval.

## Download reports

- Dashboard: http://127.0.0.1:5000
- JSON report: http://127.0.0.1:5000/report.json
- CSV signals: http://127.0.0.1:5000/signals.csv

The report endpoints refresh the analysis and return a snapshot. If no setup is confirmed, the CSV contains headers and no signal rows.

## Optional: rebuild the model from your broker's history

This is separate from live dashboard operation.

1. Open MT5 and make sure the M15 chart has enough historical data loaded.
2. Run `export_mt5_history.py` from the project folder to export closed candles to `data/raw/gold_15m.csv`.
3. Run `run_training_pipeline.bat` (or execute the commands below).

```bash
python export_mt5_history.py
python stage1_preprocess.py
python stage2_train.py
```

Do not retrain just because the script runs. Inspect the data range, missing candles, trade count, test period and metrics first. Use several years of representative broker history where possible.

## Run tests

Activate the environment, then:

```bash
python -m pytest -q
```

## Important limitations

- This is a decision-support tool, not a profitable strategy guarantee.
- The model's `p_win` display is an uncalibrated model score unless separately calibrated and validated.
- The existing backtest labels treat a same-candle SL/TP collision as a stop loss, but do not model spread, commission, slippage or execution latency.
- Chronological train/test split is a useful baseline, not a complete walk-forward or purged validation process.
- The current structure and liquidity detectors are rule-based context and may need parameter tuning for your broker's gold feed.
- D1/H4/W1 candle boundaries depend on broker server session conventions; compare them with your MT5 charts.
- Fundamental inputs (DXY, US yields, economic calendar, central-bank news) are not yet integrated.
- The suggested lot-size utility is not wired to order execution and must not be treated as an order instruction.
- Never expose the local Flask dashboard directly to the public internet.

## No-trading guarantee

The codebase is intended to be read-only. It contains no automatic order-entry workflow, and `run.py` binds only to `127.0.0.1`. Do not add `order_send`, order modification, position closing or trade-management functionality to this project.
